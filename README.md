# Resources

Extracted My Singing Monsters client assets (non-image), for mod/reference use with the NPS private server tooling.

- `xml_bin/` — the game's binary scene/graphics descriptor files (island layouts, monster animation data, etc.)
- `split_asset_pack/` — everything else from the game's asset split APK (audio, Lua scripts, XML, menus, particles, shaders, fonts, localization `.utf8` text, `json_resources`, `xml_resources`), excluding `.avif`/`.png` image assets to keep the repo lighter.
